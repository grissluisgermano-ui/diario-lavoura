# Diário da Lavoura

Caderno de campo da lavoura: atividades, chuvas, estoque de insumos, grãos em depósito, máquinas, diesel, benfeitorias e anotações.

- **Dados:** Firebase (Firestore), só acessíveis pelos e-mails autorizados em `firestore.rules`.
- **Endereço:** GitHub Pages deste repositório.
- **No iPhone:** abra o endereço no Safari → Compartilhar → **Adicionar à Tela de Início**.
- **Backup:** dentro do app, aba Lavoura → Histórico → Backup dos dados.

Detalhes técnicos para manutenção: veja `CLAUDE.md`.
